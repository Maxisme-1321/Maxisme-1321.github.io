# Huangdoubao's Little Nest 🫘

A pixel-style personal blog, hand-coded with HTML/CSS/JS by a middle school student.

## ✨ Features

- 🎨 MC pixel-style UI
- 🎲 3D dice & coins (physics animation)
- 🔮 Daily adventure fortune
- 🐋 DeepSeek big fat fish Easter egg
- 💎 Multiple hidden Easter eggs
- 🔊 Independent sound effects for all buttons
- 🌓 Light/Dark mode toggle
- 📱 Mobile-friendly

## 🛠️ Tech Stack

Pure HTML, CSS, JavaScript, no frameworks

## 📁 Deployment

1. Clone or upload to GitHub Pages
2. Set Pages branch to `main`
3. Visit `yourusername.github.io`
